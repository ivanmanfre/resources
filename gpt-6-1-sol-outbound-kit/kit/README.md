# GPT-6.1 Sol outbound kit

Prepare the research and drafts for your agency's next prospect. Start with one account so you can check every source and edit the message before using it.

## Start here

1. Read SETUP.md and open this folder in Codex with GPT-6.1 Sol selected.
2. Fill in context/agency-offer.md. Add one prospect to context/prospects.csv and paste the supporting facts into context/source-notes.md.
3. Ask: “Read AGENTS.md. Run account research on my source notes and save the brief to outputs/account-brief.md.”
4. Ask for a fit check. Once you choose an account to contact, ask for an opening message and a follow-up.

Each playbook also works as a standalone prompt. Attach AGENTS.md, the playbook and the relevant context files to a session where GPT-6.1 Sol is available. Ask the session to read AGENTS.md first. The resource page builds a copyable prompt with your inputs.

## The working files

| Playbook | Input | Result |
| --- | --- | --- |
| Account research | Public sources or pasted source excerpts | Account brief with citations and unknowns |
| Prospect fit | Your offer and account brief | Fit decision with evidence and a next check |
| Message drafts | A selected prospect and approved claims | Opening message and one follow-up |
| Reply triage | The conversation and new reply | Category, next action and a reply draft |
| Campaign review | Counts for a stated window | Reconciled rates and a proposed test |

ROUTINE.md explains how to use them each morning and at the end of the week. examples/ contains a fictional practice case and expected outputs. outputs/ starts empty so your practice results stay separate from the example.
