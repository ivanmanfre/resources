Take it with you (set up the Dell for vacation)

Your instinct's right — VS Code, then sign into Claude + GitHub. The trick is you just tell Claude to do the heavy part. Three steps:

Step 1 · On your main laptop — save everything to GitHub Once you've poked around, open Claude Code and tell it, plain English:
"Save all my skills and my whole project to a new private GitHub repo called pro-swppp-ai."
It creates the repo and uploads everything — all your skills, your whole setup.
Step 2 · On the Dell — install the tools
  • Download and install VS Code (code.visualstudio.com).
  • Add the Claude Code extension, sign in with your Claude subscription.
  • Connect GitHub when it asks — approve in the browser.
Step 3 · On the Dell — pull everything back Tell Claude Code:
"Clone my pro-swppp-ai repo and set it up here."
Everything comes back — same skills, same setup. Work on either machine; re-run Step 1 to keep them in sync.

n8n is a key, not a login — we finish wiring it together in Session 2, then you just paste your n8n key and it's connected. For vacation, Claude + GitHub is all you need.
