Before you start

A few useful details.

Can a URL show my whole network?

The lookup can only use connections visible from your profile. Each first pass reviews up to 10 visible connections and shows the actual coverage. This is a sample, so it can miss buyers elsewhere in your network. If your connections are hidden, you can use the optional export tool.

Where do I get my connections CSV?

In LinkedIn, open Settings & Privacy → Data privacy → Download your data. Request an archive that includes connections and use the Connections.csv file from the export. Some accounts label this setting “Get a copy of your data”. See LinkedIn’s export guide ↗ for current steps.

What if I only have LinkedIn’s standard export?

You can start with it. Position helps check the role. Company names alone do not show what a business does, so those records need a check. Add a company_description column using facts you have verified, then run the finder again.

Does a match mean someone wants to buy?

A possible fit matches the buyer criteria you entered. Need, budget, timing and permission to contact still need your judgment. Engagement can help you prioritize; it does not establish buying intent.

What happens to my file?

The optional CSV tool reads your file locally in this browser tab. The URL lookup sends your profile link and any buyer description to the lookup service. The service reads visible profile data and uses Claude to prepare buyer criteria. Scan access expires after 10 minutes. Connection records are returned to your browser and are not saved by the lookup service. Download the decisions you want to keep before closing the page.

How does the AI help?

The URL lookup prepares a buyer description from profile facts or the sentence you provide. Check the buyer roles and business types before starting the network lookup. The first pass then checks supplied role and business facts. The optional CSV tool works offline; its GPT-6.1 Sol review prompts can be used separately.
