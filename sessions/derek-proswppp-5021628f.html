Finish this (your homework)

None of this is required. It's just the best way to learn. Try it when you have a minute:

  • Run one real job — like your permit draft, start to finish, inside Claude Code.
  • Try /deep-research — ask it a real question, and it looks things up and comes back with a short report.
  • Try planning first — ask it to plan a small job, fix the plan, then tell it to go.

A few tricks (things you picked up)

  • Tell it to think harder — for a tough job, say "think hard." For quick stuff, leave it normal. Saves time and money.
  • Don't chase every new tool — when you see a new AI thing, just ask Claude "is this better than what I already have?" and let it tell you.
  • Summarize anything long — paste a video link or a long document and ask for the three-sentence version.

Take it with you (set up the Dell)

You had it right: install VS Code, then sign into Claude and GitHub. The trick is you just tell Claude to do the hard part. Three steps:

Step 1 · On your main laptop — save everything to GitHub When you're done playing around, open Claude Code and tell it:
"Save all my skills and my whole project to a new private GitHub repo called pro-swppp-ai."
It builds the repo and uploads everything — all your skills, your whole setup.
Step 2 · On the Dell — install the tools
  • Download and install VS Code (code.visualstudio.com).
  • Add the Claude Code extension and sign in with your Claude account.
  • Connect GitHub when it asks — just approve it in the browser.
Step 3 · On the Dell — bring it all back Tell Claude Code:
"Clone my pro-swppp-ai repo and set it up here."
Everything comes back — same skills, same setup. Work on either laptop, and run Step 1 again to keep them matched.

n8n is a key, not a login. We'll finish that part together next time — then you just paste your key. For your trip, Claude and GitHub are all you need.
